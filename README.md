接口用游标翻页之后，攻击者把返回的游标原样改成另一个租户的值，就开始一条条翻别人的订单：服务端只按游标携带的位置继续往后翻，从不核对这份游标属于哪个租户，越权读取既不报错也不留痕。修复后必须满足：游标唯一定位一条记录，下一页从该记录之后开始；同一排序键的记录不重复、不遗漏，并按稳定次序排列；游标被篡改时必须经签名或等价校验识别并拒绝；末页之后返回的下一页游标为空；页大小改变后已经发出的游标仍然有效；完整翻完全部记录后得到的集合与原始集合相等且没有重复；同一个游标重复请求返回相同结果。

数据约定：每条记录是以字段名为键的字典，并带有唯一的 id；排序字段由调用方给出，按升序比较，空值排在最后；排序键相同的记录按 id 形成稳定次序。

接口约定：分页返回当前页记录与下一页游标；批量请求中的每个请求各自携带记录集合、排序字段、页大小与游标，彼此独立；游标只通过公开的编码与解码接口产生和读取。
